Change Log

Inventory Management  ·  1 – 4 September 2026
Mon 1 Sep New screen

Vendor spend and invoices in one place

Admin → Operations → Vendor Management

To find out what we paid a vendor, you had to search the stock-in records one kitchen at a time. The old screen only stored vendor names.

Before
A list of names. No spend, no invoices.
Now
Spend per vendor, every invoice, and four downloads — over any date range.
Also fixed

458 of our 462 invoices are PDFs, and none of them would open on screen. You had to leave the page to see the document. They now open in place.

Wed 3 Sep Improvement

Requisition reports for one outlet

Admin → Reports & Analytics → Requisitions Reports

The question is usually about one outlet in the last week. The report could not answer that.

Before
All outlets, last 30 days only.
Now
Pick one outlet, and pick 7 or 30 days.

For a single outlet the report also shows how often each item was asked for, and what was requested against what was actually given.

Wed 3 Sep Behaviour change

Closing sheets no longer move stock by themselves

Supervisor → Closing form  ·  Purchase Manager → Returns

When a closing sheet was confirmed, the system put the returned stock back into inventory on its own. Nothing else works that way — the purchase manager keys in every other stock movement.

It also got the value wrong. Returns came back without GST, while all other stock includes it. An item never bought in that kitchen came back valued at zero.

Before
Confirming a sheet quietly added stock back, at the wrong price.
Now
The sheet is only a record. The purchase manager keys the stock in.

A new Returns screen lists what came back over any date range, added up by material. That total is the list to key in.

Two things to know

This is a temporary step. The plan is for the dispatch to take stock out and the closing sheet to put it back — both ends together, so they always agree. The old version did only one end, so returns came back without the dispatch ever going out.

Old records were left alone. Undoing them now would subtract twice wherever someone has already fixed a count by hand.

Fri 4 Sep New capability

Each kitchen sets its own low-stock level

Admin → Operations → Materials → Edit a material

Every item had one low-stock level for the whole company. CK2 is a central store and holds far more, so one number never fitted all three kitchens. It was either too high, marking everything low, or too low to warn about anything.

Before
One number per item, for every kitchen.
Now
One number for all kitchens, plus a box for any kitchen that needs its own.

Leave a kitchen blank and it follows the main number. All 331 existing levels carried over — nothing was re-entered. Only the admin can change these.

Wed 3 Sep Internal

Notes on why the system works the way it does

No screen — internal

Some things in the system look like mistakes but are deliberate. We now keep a short note on each one.

Example: the day does not change over until 5:30am, so a late shift’s work stays on the day it started. Someone once “corrected” this, and it broke the closing form for anyone working past midnight.
